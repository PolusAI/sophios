# Hello World

## Writing a workflow

First we will start with the classic Hello World example:

```yaml
steps:
  echo:
    in:
      message: !ii Hello World
```

A workflow is an ordered sequence of steps. Here we just have a single step, which executes the unix `echo` command with the input `Hello World`. Workflows are written in YAML format. We will discuss the YAML syntax later, but for now just note that **indentation is important**. In particular, the `in:` tag must be indented two spaces beyond the step name (`echo` in this case). Similarly, all of the inputs must be indented two spaces beyond the `in:` tag (`message` in this case).

## Running a workflow

```bash
sophios --yaml docs/tutorials/helloworld.wic --run_local --outdir helloworld_output --quiet
```

That command compiles the workflow into `autogenerated/`, runs it locally with the configured CWL runner, and writes primary outputs into `helloworld_output/`.

On success, the final message tells you where the runner outputs were written.

* The files that were compiled (starting ... finishing)
* The command that was used to invoke the cwl runner
* The output of the cwl runner
* The location of the output metadata json file
* The configured output directory for the runner

For this workflow, the runner output directory contains the file produced by the `echo` step, and that file contains `Hello World`.

On the other hand, if something went wrong you will see, on stderr, a line for each step that failed:
```
Failure! step 1 'echo' (helloworld__step__1__echo) exited with status 127, which means its command was not found: the tool's baseCommand is not installed in its container image, or on this machine for a tool with none. Its own messages are above, under its name.
```

Sophios names each step that failed and how it ended; the step's own messages are above, under its name. If they are not enough, run again without the `--quiet` flag.

Finally, to avoid recalculating unchanged steps, run with `--cachedir cachedir`: cwltool then keeps a cache there. If you suspect that a stale artifact is involved, you can remove `autogenerated/`, `cachedir*`, `helloworld_output/`, `outdir*/`, and `provenance/` and then run the workflow from scratch.
